Subject: Howard Kaikow's Excel Fix Time Workbook

Download the latest version of the program to create and use Howard Kaikow's Excel Fix Time Workbook

Overview

On 11 May 2009, I switched from using the local telephone company to a cable company for voice telephone. They allow downloading a history of dialed, received and missed calls. It is likely that other cable/VOIP/etc. companies also offer this information for download.

I expected to be able to open a Microsoft Excel workbook, and copy the data into the workbook, then perform simple operations, such as using Excel's SUM function to find out how much time I had spent on the phone, and for particular numbers.

It was disappointing to find that the SUM function produced a value of 0, unless I manually massaged the imported data..

Of course, since I would be downloading more data at least 1-2 times per month, the manual fixing of things would get rather tedious. So being a programmer, I have written an Excel macro to do the deed.

I have decided to allow others to use the macro, with the hope that companies will change the way they export the data, perhaps, eliminating the need for the macro or manual massaging of the data.

Installing the program and DLL

Download the latest version of the program to create and use Howard Kaikow's Excel Fix Time Workbook

Run the HowardKaikowExcelFixTime.exe program. The program will:

  • Install the DLL in a directory of your choosing, and will include the following in a group of your own choosing in the Start menu.
    • A shortcut to run CreateWorkbookFixTime.exe, the program that creates the workbook.
    • A shortcut to uninstall the DLL. The DLL may also be uninstalled from Add/Remove Programs in the Control Panel.
  • Provide a program, CreateWorkbookFixTime.exe, that may be used to create a workbook, in a directory of your choosing. You will be given an opportunity to create a workbook just after the DLL has been installed.
    You may also run the CreateWorkbookFixTime.exe program after the installation of the DLL. The workbook includes the code necessary to run the macro using the installed DLL. The macro is called FixTime. A toolbar button is provided to run the FixTime macro. The toolbar is created each time you open the workbook, and deleted when you close the workbook.

Requirements

The DLL and EXE were compiled using Microsoft Visual Basic 6 (with SP 6) and Microsoft Office 2003. The program should work with Microsoft Excel 2003 and 2007. I have intentionally not compiled the program to use Excel 97, Excel 2000 and Excel 2002, as I could not justify the time to do so and to test such options.

To use the DLL and CreateWorkbookFixTime.exe, please note the following requirements:

  • Either Microsoft Visual Basic 6 or the Microsoft Visual Basic 6 run-time files: If you have neither, then you can download the Visual Basic 6 run-time files by following the instructions in VBRun60.exe Installs Visual Basic 6.0 Run-Time Files.

    The program will not run on an OS earlier than Microsoft Windows 2000, so you should already have the Visual Basic 6 run-time files installed.

    I believe that both Microsoft Office 2003, and 2007 already have the Visual Basic 6 run-time files installed.

How to use the workbook and Fix Time macro

The workbook is created with the code necessary to run the macro and a reference to the DLL. In addition, there is code that automatically creates the toolbar each time you open the workbook and deletes the toolbar each time you close the workbook.

The macro is used by selecting the troublesome cells in the workbook, then clicking on the Fix Time button on the toolbar. In Excel 2003, the toolbar should default to being visible, if not make the toolbar visible. In Excel 2007, one has to click on the Addins menu to display the toolbar.

To give you an idea of how to actually use the workbook, the following is a description of what I have done since 11 May 2009:

  • On 1 June 2009, I downloaded the history files from my cable phone provider. The files were formatted as TAB delimited text files.
  • I then tried a number of different ways to import the data into a Microsoft Excel 2003 workbook. In each case, I ran into the problem I described in Overview. THe easiest way to import the values is to COPY them from the text file, and PASTE into the desired cells in each worksheet.

    I fiddled around, and was able to get the data into a form that would work with the SUM function. Obviously, this would be too tedious to go through when I added more data, at least once per month.

  • The macro, DLL, and EXE are now in a form that allows me to make the critters available to others.
  • So how did I use the macro on 19 June 2009?
    • I used the CreateWorkbookFixTime.exe program to create a workbook that has the macro and toolbar
    • The workbok is created with 3 worksheets, so I copied the worksheets from the workbook that I had manually created in early June 2009.
    • Next, I downloaded the most recent history for dialed, received and missed calls, copying information for new calls into the relevant worksheet, at the end of the previous corrected data.
    • I then selected each set of cells that have data on new calls and ran the macro to fix things.

    Once the current values have been corrected, each time one adds data, it is only necessary to apply the two bolded steps above.
