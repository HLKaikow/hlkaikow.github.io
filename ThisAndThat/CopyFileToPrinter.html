It is sometimes necessary to copy a file to a printer, i.e., treat all the bytes in the file as printable characters, including format effectors such as carriage return, linefeed and formfeed.

If you already have a document containing printer codes (e.g., PCL, PostScript, or man pages), the program facilitates sending the byte stream to the printer without the interference of an application. Printing via an application usually causes the application to format the document for printing, causing the misinterpretation, or loss, of the aready included printer codes.

There is no installation necessary, just directly run the program, create a shortcut to run the program.

I have run this program only in Windows 2000. This program will not run in a version of Windows earlier than Windows 2000.

Download CopyFileToPrinter.zip.

In order to run this program, you will need to have installed either Visual Basic 6 or the Visual Basic 6 run-time files. If you have neither, then you can download the Visual Basic 6 run-time files by following the instructions in VBRun60.exe Installs Visual Basic 6.0 Run-Time Files.
