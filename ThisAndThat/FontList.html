There is no installation necessary, just directly run the program, or create a shortcut to run the program.

I have tested this only in Windows 2000.

In order to run this program, you will need to have installed either Visual Basic 6 or the Visual Basic 6 run-time files.

If you have neither, then you can download the Visual Basic 6 run-time files by following the instructions in VBRun60.exe Installs Visual Basic 6.0 Run-Time Files.

If you are running Windows ME, NT, 2000, or XP, you should already have the Visual Basic 6 run-time files installed.

If you have Office 2000 or Office XP, I believe that you may already have the Visual Basic 6 run-time files installed.
