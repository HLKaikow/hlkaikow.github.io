# standards-site
This repository contains Howard Kaikow's work, the source files for Standards.com, a long-running collection of technical articles, utilities, and code examples focused on practical problem-solving in software development.

Standards.com is a curated library of content Howard created covering:

File system utilities and comparisons
Performance testing and benchmarking techniques
Microsoft Word / VBA automation and troubleshooting
Cross-platform development insights
Real-world programming edge cases and solutions

The site emphasizes hands-on examples, working code, and clear explanations drawn from real development scenarios.
