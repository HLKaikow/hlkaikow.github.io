In order to use a Visual Basic 6 program, e.g., a DLL or EXE file, you will need to have installed either Visual Basic 6 or the Visual Basic 6 run-time files. If you have neither, then you can download the Visual Basic 6 run-time files by following the instructions in VBRun60.exe Installs Visual Basic 6.0 Run-Time Files.

VBRun60sp6.exe installs Visual Basic 6.0 SP6 run-time files ..

If you are running Windows ME, NT, 2000, or XP, you should already have the Visual Basic 6 run-time files installed.

If you have Office 2000 or Office XP, I believe that you may already have the Visual Basic 6 run-time files installed.
